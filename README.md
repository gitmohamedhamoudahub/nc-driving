# دليل القيادة – نورث كارولينا (NC Driver Handbook study tool)

تول مذاكرة بالعربي لامتحان القيادة في ولاية نورث كارولينا: كروت شرح، امتحانات، لعبة، ورحلة مذاكرة بنجوم ومستويات وأوسمة.

- الموقع: https://gitmohamedhamoudahub.github.io/nc-driving/
- صفحة واحدة ثابتة (`index.html`) من غير build.
- التقدّم بيتحفظ في المتصفح، ولو الجهاز مربوط بيتزامن مع ريبو بيانات خاص عن طريق GitHub API.
- `users.json` هنا نسخة احتياطية بتتستخدم لما الجهاز مش مربوط.
